# Data

This folder contains the fully synthetic FY2025 data used by the Power BI report.

## Scope

| Item | Value |
|---|---:|
| Reporting period | January 2025 - December 2025 |
| Performance rows | 1,440 |
| Expense-recovery records | 540 |
| Data-quality issues | 120 |
| Clients | 24 |
| Products | 5 |
| Regions | 4 |
| Bankers | 12 |
| Currency | CAD |

## Files

- `CIB_Performance_Expense_Analytics_Synthetic_Data.xlsx` - original multi-sheet source workbook.
- `csv/` - CSV exports of the fact tables, dimensions, and data dictionary for reproducible SQL analysis.

## Disclosure

All clients, bankers, projects, vendors, transactions, issues, and financial values are fictional. The data does not contain, reproduce, or infer confidential information from TD Bank, TD Securities, or any other organization.
